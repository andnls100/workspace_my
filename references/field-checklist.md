# 审核字段清单

## A. 项目归属
- [ ] 项目/标段名称、编号、招标人/发包人、中标人/承包人
- [ ] 确认招标文件、合同、公示属于同一项目；不匹配时停止交叉对比

## B. 条款提取与一致性
- [ ] 合同协议书、通用条款、专用条款、附件格式
- [ ] 合同价/计价方式、金额大小写、工期及起算条件
- [ ] 质量标准、项目负责人、承包范围、付款、履约担保、违约责任
- [ ] 变更调价、争议解决、合同生效、附件和特别约定
- [ ] 日期逻辑、附件是否缺失、招标文件禁止的选项是否被选择

## C. 隐私信息
- [ ] 手机号、QQ号、身份证号、疑似个人银行账号
- [ ] QQ号有明确语境；银行账号结合上下文判断
- [ ] 所有报告和原文摘录均脱敏
- [ ] 区分个人账户、单位对公账户、统一社会信用代码

## D. 未填写/空白项
- [ ] 半角下划线、全角下划线和变体字符（＿、﹍﹎﹏）
- [ ] 日期/金额等多槽位占位符，检查部分填写情况
- [ ] 空白括号、未选方框；区分已选/未选状态
- [ ] “待定/待补充/另行填写/此处注明”等提示语
- [ ] 冒号后为空的字段标签
- [ ] DOCX 下划线格式、表单域、空单元格；合并单元格去重
- [ ] PDF 版式横线（若启用版式检测）；人工查看页面图像
- [ ] 招标文件要求填写但合同对应位置仍为空
- [ ] 区分正常签字/盖章留白与业务字段缺失
- [ ] 每项记录页码、条款位置、来源层、脱敏原文、建议和风险
- [ ] 同条款/表格问题合并，按风险排序并统计

## E. 必填性与风险参考
| 字段 | 默认判断 | 风险 |
|---|---|---|
| 签字、签名、盖章、签署日期、签订地点 | 可能为正常签署留白 | 低 |
| 合同价款、工期、起算条件、金额大小写 | 核心业务字段 | 高 |
| 质保金比例、违约金率、履约担保、收款账户、争议管辖、项目负责人 | 关键业务字段 | 高 |
| 联系人、送达地址、交付地点、附件清单 | 履约细节 | 中 |
| 可能表示“无/不适用”的空单元格 | 语义待确认 | 低/待复核 |

高＝可能影响价款、工期、责任、担保、管辖或关键主体；中＝可能影响履约、送达、交付或附件；低＝形式完备或正常签署留白；待复核＝字段含义、签署阶段或来源不明。

## F. 报告质量
- [ ] 每项结论附原文证据、页码或 URL
- [ ] 结论使用一致/不一致/无法核实/需人工复核
- [ ] 隐私信息脱敏，空白清单不得泄露完整号码
- [ ] 标明检测来源：文本层、DOCX格式层、PDF版式层、OCR
- [ ] 说明漏检/误报限制
