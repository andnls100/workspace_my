# 审核字段清单

## A. 材料处理
- [ ] 默认上传材料属于同一项目，不单独执行 AI 项目归属判断
- [ ] 发现项目名称、编号、主体明显冲突时记录并提示人工确认
- [ ] 原始 PDF/DOCX 用于隐私、空白和格式扫描
- [ ] 转换 TXT 用于条款提取、合同内部逻辑检查及跨文件比较
- [ ] TXT 保留 PDF 页码或 DOCX 段落/表格位置；不编造页码

## B. 关键字段提取
- [ ] 价格形式/计价方式、合同金额/中标价
- [ ] 施工工期、设计工期、服务期限、开始日期、完成日期、起算条件
- [ ] 付款方式、预付款比例、付款节点和条件
- [ ] 可调整的材料范围、可调整的波动幅度、调价规则和计算基数
- [ ] 保修期、缺陷责任期
- [ ] 甲方、乙方、项目负责人、技术负责人
- [ ] 履约保证金金额、比例、提交期限和退还条件
- [ ] 每个字段保留 value、status 和 evidence；多处不同取值保留全部证据
- [ ] 区分已提取、原文未载明、不适用、无法提取、存在冲突、待人工复核

## C. 合同自身错误
- [ ] 错别字、漏字、重复字、明显语病和标点错误
- [ ] 项目名称、甲乙方、负责人等前后不一致
- [ ] 金额大小写、总价与分项合计、税额和付款金额计算
- [ ] 付款方式、预付款比例、付款节点及条件相互矛盾
- [ ] 工期、期限、起算条件和日期逻辑冲突
- [ ] 保修期、缺陷责任期及履约保证金相关条件矛盾
- [ ] 计价方式、材料调价范围、波动幅度和调价规则矛盾
- [ ] 条款编号跳号/重复、交叉引用错误、模板残留及关键内容遗漏
- [ ] 区分确定错误、疑似问题和需人工复核

## D. 隐私信息（基于原始文件）
- [ ] 手机号、QQ号、身份证号、疑似个人银行账号
- [ ] QQ号有明确语境；银行账号结合上下文判断
- [ ] 区分个人账户、单位对公账户、统一社会信用代码
- [ ] 所有报告和原文摘录均脱敏
- [ ] 说明 OCR、图片、手写及格式变形导致的漏检风险

## E. 未填写/空白项（基于原始文件）
- [ ] 半角/全角/变体下划线及部分填写的多槽位字段
- [ ] 空白括号、未选方框、待定/待补充/另行填写等提示语
- [ ] 冒号后为空的字段标签、空单元格、DOCX 下划线格式和表单域
- [ ] PDF 版式横线（若启用）；人工查看页面图像
- [ ] 招标文件要求填写但合同对应位置仍为空
- [ ] 区分正常签字/盖章留白与业务字段缺失
- [ ] 每项记录来源、位置、脱敏原文、建议、风险并去重

## F. 跨文件比对与报告
- [ ] 复用已提取字段和证据，不重复全文提取
- [ ] 对比主体、金额、计价方式、期限、负责人、付款、调价、保修、保证金及重要责任条款
- [ ] 公示未披露的事项标记“公示未载明”，不推断为一致
- [ ] 结论使用一致、不一致、无法核实、需人工复核
- [ ] 每项结论附原文、文件名、页码/位置、条款编号或 URL
- [ ] 合并重复问题，按风险排序；最终校验只核证据、结论、遗漏和脱敏

## G. 风险参考
| 字段 | 默认判断 | 风险 |
|---|---|---|
| 签字、签名、盖章、签署日期、签订地点 | 可能为正常签署留白 | 低 |
| 合同价款、工期、起算条件、金额大小写 | 核心业务字段 | 高 |
| 质保金比例、违约金率、履约担保、收款账户、争议管辖、项目负责人 | 关键业务字段 | 高 |
| 联系人、送达地址、交付地点、附件清单 | 履约细节 | 中 |
| 可能表示“无/不适用”的空单元格 | 语义待确认 | 低/待复核 |

高＝可能影响价款、工期、责任、担保、管辖或关键主体；中＝可能影响履约、送达、交付或附件；低＝形式完备或正常签署留白；待复核＝字段含义、签署阶段或来源不明。
